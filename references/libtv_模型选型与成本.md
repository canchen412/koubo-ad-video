## 二、分辨率倍率（经验值，用于估 1080P / 4K）

- 1080P ≈ 720P 的 **1.5–2.5 倍**（Kling 1.5×，Seedance 2.5 约 2.5×）
- 4K ≈ 720P 的 **3–4 倍**（Kling 3.0 4K ≈ 3.3×）
- 结论：纪录片/短视频交付一律 720P 出，别为清晰度买单（与「AI 素材 720P」铁律一致）。

## 四、五条省钱流水线

1. **480P 样片定构图 → 720P 出成片**：同 prompt 两段跑，中了的才升清。
2. **首帧图锁形象**：i2v 比 t2v 少抽卡，人物不漂，废片率直降。
3. **2s / 4s 短切**：按秒计费，长段出废就是整段烧；短切只重跑坏的那一截。
4. **难镜头挑活动期跑**：Kling 4.0 / Wan 3.0 / H3 现在 0 积分，先把难的跑完再考虑付费模型。
5. **不要拿参考视频续写**：Seedance 2.5 等模型的 `pricingRule` 明确「上传的参考视频时长计入总时长」，带参考视频贵 1.5–2.6 倍；截关键帧当首帧更省。

## 五、注意

- 失败任务不按「成片」退，重抽就是你自己的成本；按「一条成片 ≈ 3 次抽卡」做预算。
- 官方价随活动变（双11 到倒计时结束），下单前以创作台确认页为准，本文数字过期就重算。
