# 封面帧 · 定式（2026-10-29 灿爹拍板「以后封面就这样做」· 2026-10-30 两次修订）

> 一句话：**封面取自「视频池抽帧」或「分镜底图」（首选无产品的动作帧），取 3:4 竖幅，居中放在 16:9 中间，做视频第 0 帧停留 0.5 秒。**
> 判据来源：261029 VORSE 姜黄素（灿爹「这张封面就做得很好」）+ 261030 诺特烟酰胺两次打回（「不要用产品当封面」「尽量不要用产品出现在封面里」）。

## 一、四条铁律

| # | 铁律 | 为什么 |
|---|---|---|
| 0 | **封面主体必须是 IP 人物本人**；**首选画面里没有产品的纯人物瞬间**，产品当手持道具是次选，**禁止用「只有瓶子/罐子」的产品图做封面** | 2026-10-30 灿爹两次原话：①「**封面不能就用那个 21 金维他这个瓶子，封面要用小绿人，小绿人最有冲击力的一幅**」②「**这个封面尽量不要用产品出现在封面里，可以截取底图视频里面的一帧具有冲击力的画面，也可以截取图片里面一帧的画面**」。纯产品瓶＝货架图，信息流里没有对视感、没有肌肉张力；带产品的图就算人再猛，第一眼也容易被读成「又一条广告」，**纯人物动作帧（出拳、力竭、腾空、对视）才是第一眼抓人的构图** |
| 0b | **相邻两条片的封面不许撞脸**：同一 IP、同一产品，第二条起必须换素材类型（上一条用产品怼镜头 → 这条就用力竭/出拳的动作帧） | 2026-10-30 灿爹原话：「**最好不要和之前的封面相重复，重复过多**」。同一个号连着两条一模一样的构图，等于把老观众劝退、把新观众当成重复投放 |
| 1 | **封面取自「分镜底图」或「视频素材池抽帧」**（`分镜图库/<IP>/视频素材/*.mp4`），**不许从成片截帧** | 成片截图会把**字幕、98% 圆环、重点字/更便宜**这些东西一起带进去。261029 第一版就是从成片 20.9s 截的，画面底部压着「配料表每粒 300mg」，96% 的封面都是这样废掉的。视频池抽的帧是干净的原始画面，且天然无字幕 |
| 2 | **只取 3:4 竖幅**，且**几何居中**放在 16:9 画布中间，两侧**纯黑**填充 | 抖音按 3:4 居中裁 16:9 时，裁切宽 = 画布高 × 0.75 = 810、起点 x = 555，**正好命中这块竖图**，一点黑边都不带进去。偏一寸就会带黑边或切掉主体 |
| 2b | **产品只要出现在封面里，瓶身/罐身的水平中心必须压在画面中线 x=960**（差 5% 就是歪的） | 2026-11-01 灿爹原话：「**只要产品出现在封面里，产品一定要居中对齐**」。261101 赛霸那条瓶心在 1055（偏右 95px≈5%），第一眼读成「没对齐」。**量法**：白瓶用「mx>170 且 (mx−mn)<40」做列投影求 bbox，**搜索必须限制在中区 x∈[500,1100]**——两侧白色护腕会把 bbox 撑到 550~1150、中心算成 850，全是假的。**落位**：移动景观取窗 `x0 = 瓶心 − 窗宽/2`，让瓶心落到取窗中心；**不许平移主体、不许抠图补胸口背景**去凑（会切手/露接缝）。取窗被 3:4 锁死切手时，**宁可加宽清晰区**（261101 实测 810 → 1188），两侧用同源图 `blur40 + brightness0.65` + 90px 正弦缓入渐变消融 |
| 3 | **必须是视频第 0 帧**，停留 **0.5s（15 帧 @30fps）** | 平台抓首帧做封面；0.5s 是为了兜住「有的端取 0.5s 附近那一帧」的差异。1 帧（0.034s）太薄，容易被跳过 |

## 二、选哪张底图

### 2.0 先选来源：视频池抽帧 > 图片底图

| 顺序 | 来源 | 什么时候用 |
|---|---|---|
| **首选** | `分镜图库/<IP>/视频素材/*.mp4` 抽一帧 | **默认走这条**。视频素材本身就是「动态瞬间」，抽出来的帧天然带动作张力，而且**全部无产品**，正合铁律 0。小绿人池子里力竭、出拳光爆、腾空、碎镜对视这些帧，比任何静态产品图都猛 |
| 次选 | `分镜图库/<IP>/<产品>/图片/*.png` 静态底图 | 视频池里实在没有贴题的动作时才退回来，且优先挑**人物占满竖幅、产品在手里不在正中间**的那张 |

抽帧要点（2026-10-30 实测）：
- 素材普遍 1280×720。3:4 窗口 = **540×720**（高度撑满、宽度 = 高 × 0.75），放大 **1.5×** 到 810×1080。
- 1.5× 放大务必补 `unsharp=5:5:0.35`，否则皮肤纹理发糊；出图后**缩到 216 宽再目视一遍**（模拟信息流缩略图），小图能看清动作才算过关。
- **同一段素材是持续运镜的**（推近 / 拉远），要逐个时间点试，别只用 2.5s。261030 力竭那条 0.6s 是全身、4.4s 已经糊成大特写，只有 2.5s 是「半身 + 握杠铃 + 直视镜头」的甜点。
- 横向只能挪窗口位置：`crop=540:720:X:0`，X 从 `(1280−540)/2 = 370` 起，主体偏一侧时按 120~150px 步进试（261030 出拳帧最终用 X=500，把出拳手臂和火花都收进来了）。

### 2.1 再打分

> **第 0 关（一票否决）：画面里必须站着 IP 人物**。只有产品瓶/罐/盒、或只有一只手托着瓶的，
> 直接淘汰，不参与打分。2026-10-30 灿爹把「收尾_巨型瓶金色爆发」当封面的版本打回就是这个原因。

1. **有动作或有对视**（出拳 / 发力 / 力竭抬头直视 > 正面站立 > 侧身 > 背影）
2. **动作肢体的末端不能被裁掉**——出拳的手、举起的瓶，3:4 窗口必须把「打到哪儿」收进来；裁在手腕上等于动作废了
3. **主体在竖向中轴上**，左右各留一点余量（3:4 只有 810 宽，主体一偏就被切）
4. **背景是暗调或纯色**——两侧黑边与背景同色系时过渡自然，亮背景会像贴了块白板。暗场动作帧（出拳光爆、力竭）在缩略图里明暗对比最抓眼
5. **画面里除了人（和手持产品）没有别的信息**（避开带字幕/带问号警示/带对比双人的图）
6. 若画面里出现产品，瓶身品牌字**不能被切**；但**不要为了保住瓶身字牺牲动作**——这一条优先级低于 1、2

## 三、裁切怎么算（别凭感觉拖）

底图三种常见尺寸，3:4 窗口按「高度撑满、宽度 = 高 × 0.75」算：

| 底图 | 3:4 窗口 | 放大到 810×1080 |
|---|---|---|
| 1536×1024（1.5） | 768×1024 | 1.055× |
| 1536×864（1.78） | **648×864** | **1.250×**（放大 >1.1 时补 `unsharp`） |
| 2730×1536（1.78） | 1152×1536 | 0.703×（缩，不锐化） |
| **1280×720（视频帧，1.78）** | **540×720** | **1.500×（必须补 `unsharp=5:5:0.35`）** |

- **横向只能选窗口位置，纵向不能移**（高度已经撑满）。所以选窗前必须看主体是否居中被切。
- 3:4 窗口 x 的取法：默认几何居中 `(W − w) / 2`；主体偏一侧时手动微调，但**每次只挪 60~80px 逐步试**，三档并排出图目视选（261029 试了 x=360/444/520，444 最对称）。
- 放大超过 1.1 倍时加 `unsharp=5:5:0.5:5:5:0`，补偿清晰度；底图有效宽度不足 810 的（如 648 宽），直接告诉灿爹「再大要回图库出高分辨率版」。

### 3.1 画面里有产品时：先算瓶心，再定取窗（2026-11-01 新增）

3:4 窗口只有 810 宽，**产品居中和「人物双手完整」经常打架**（261101 赛霸：源图 1536×864，瓶心 844 = 偏右 76 源像素；右手到 1330、左手从 380 起，跨度 950 源像素 > 648 取窗）。三条路别走错：

| 做法 | 结果 |
|---|---|
| ✅ **加宽清晰区**（把「3:4 竖幅」换成「宽竖幅」） | 清晰区 1188 → 取窗 950×864（仍 1.25×），`x0 = 瓶心 844 − 475 = 369`，瓶心落 `460+(844−369)×1.25 = 960` ✓；左右手全在窗内 |
| ❌ 3:4 死守 648 取窗 + 右移取窗 | 瓶心确实到 960，但左手被丢 76 源像素＝**整只手掌出框**，断手 |
| ❌ 抠瓶平移 + 镜像补胸口 | 接缝必露（胸口中缝/光影方向反），且要动 1080 帧里的一帧，风险不成比例 |

**加宽后的合成式（261101 定稿参数）**：

```python
bg  = src.resize((1920,1080)).filter(GaussianBlur(40)); bg = brightness(bg, 0.65)
CARD_W, SCALE = 1188, 1.25; win_w = 950
x0  = int(round(瓶心 - win_w/2))                      # 369
fg  = src.crop((x0,0,x0+win_w,864)).resize((CARD_W,1080))
px  = (1920-CARD_W)//2                                # 366
# 90px 正弦缓入渐变，左右消融（去掉硬边画框感）
mask[:, px:px+FADE] = sin(t*pi/2)**2 ; mask[:, px+CARD_W-FADE:px+CARD_W] = 反过来
out = bg*(1-mask) + fg*mask
```

- 为什么不用纯黑边：261101 起改「同源图模糊压暗 + 渐变消融」，1680 宽的虚化带照样满足「3:4 居中裁不带黑边」（裁切区间 555~1365 全在核心清晰区 458~1466 内），观感比纯黑高级。
- **量完必复核**：出图后重新跑一次瓶心检测（中区限制），落点与 960 差 >10px 就重算 `x0`；再与正片第 1 帧比对，`abs mean diff < 2` 才算接缝无跳变。

### ② 出片时自动带（pipeline）

config 里加两项，第 6.5 步自动贴：

### ③ 手工 ffmpeg（没脚本时照抄）

```bash
# 1) 3:4 竖幅（放大 + 轻锐化）
ffmpeg -y -i 底图.png -vf "crop=648:864:444:0,scale=810:1080:flags=lanczos,unsharp=5:5:0.5:5:5:0" -frames:v 1 cover34.png
# 2) 居中贴 16:9 纯黑
ffmpeg -y -f lavfi -i "color=c=black:s=1920x1080" -i cover34.png \
  -filter_complex "[0:v][1:v]overlay=555:0:shortest=1" -frames:v 1 cover169.png
# 3) 贴第 0 帧（0.5s）+ 音频后移 500ms
ffmpeg -y -loop 1 -t 0.5 -framerate 30 -i cover169.png -i 成片.mp4 \
  -filter_complex "[0:v]scale=1920:1080,fps=30,format=yuv420p,setsar=1[a];\
[1:v]fps=30,format=yuv420p,setsar=1[b];[a][b]concat=n=2:v=1:a=0[v];\
[1:a]adelay=500|500,apad[au]" -map "[v]" -map "[au]" \
  -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p -r 30 \
  -c:a aac -b:a 192k -ar 44100 -ac 2 -movflags +faststart -shortest out.mp4
```

★ 音频**必须 `adelay` 同长**，否则开口比画面对齐位置晚 0.5s，全片错位。

## 六、交付前自检（四条，缺一条就会翻车）

```bash

#   帧 0 与帧 14 应为同一张带左右黑边的竖图，帧 15 起才进正片

# ② 布局对不对：中间 3:4 有内容、左右黑边 ≈ 0
python - <<'PY'
from PIL import Image; import numpy as np
a=np.asarray(Image.open("f_01.png").convert("L"),dtype=float)
print("中间 %.1f 左 %.2f 右 %.2f"%(a[:,555:1365].mean(), a[:,:555].mean(), a[:,1365:].mean()))
PY
```

## 七、踩过的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 用成片截图当封面 | 封面底部带字幕、右侧带「更便宜」红字、98% 圆环 | **只用底图**，铁律 1 |
| 3:4 不居中 | 平台裁 3:4 时带进黑边或切掉半边人 | x 必须 = (画布宽 − 810)/2 = 555 |
| 只贴 1 帧 | 有的端抓到第 2 帧，封面变成正片首帧 | 停留 0.5s（15 帧） |
| 忘记 adelay | 开口比画面晚 0.5s，全片音画错位 | concat 时 `adelay=dur*1000` |
| `-vsync` | `Unrecognized option 'vsync'`（ffmpeg 9.0 已删） | 用 `-fps_mode passthrough` |
| 底图有效宽不足 | 648 宽放大到 810 略软 | 加 `unsharp=5:5:0.5`；要更大尺寸回图库出高分辨率版 |
| 想同时要人和罐 | 横图 3:4 窗口只能二选一 | 换一张「人+产品同框居中」的底图，别硬裁 |
| 视频帧 720p 放大 1.5× | 缩略图尚可、全屏发软 | 抽帧时加 `unsharp=5:5:0.35`；出图后缩到 216 宽复核，肉眼过关再用 |
| 只在 2.5s 抽一帧 | 同一段素材是运镜的，别的时间点可能才是甜点 | 按 0.6/1.5/2.5/3.4/4.4s 抽五帧并排选 |
| 连续两条封面同构图 | 老观众当重复投放刷走 | 见铁律 0b + 第二节「已用过的封面」表 |
