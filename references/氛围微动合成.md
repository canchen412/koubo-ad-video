# 氛围微动合成（静图 → 会呼吸的视频，0 积分）

> **2026-11-06 立**，起因是断崖镜（`产品_巨型断面烤肠当断崖仰视_大远景.png`）连续 **10 版全部失败**，
> 老板最后给的原话是：
> 「它和近图然后去放大没有任何区别，因为它石头也没动，氛围也没动，那一滴肉肠上的那一滴水也没有往下动。
> 人物可以微微动，运镜也可以不动，但是那些周围的氛围感、石头啊、那一滴油啊这些一定要动起来。」
>
> **结论一句话**：这类图的出路不是换模型、不是改提示词，是**别用 i2v**，改用「原图 + 分层程序化动画」。
> 引擎：`scripts/ambient_motion.py`（纯 PIL + numpy + ffmpeg，不花一分积分）。

## 一、什么时候走这条（判据）

先过 `i2v_提示词规范.md` 〇之四「选图五条硬规则」：

| 图上情况 | 做法 |
|---|---|

| 主体居中、单主体、中景（人物 45–65%） | ✅ 正常走 Wan 2.7 / Mini |

**10 秒判决法**：把图缩到手机大小看第一眼，**如果被「不是主角的东西」吸走 → 走本文**。
模型的第一眼和你一样，它会推过去重画。

| 版本 | 模型 | 提示词写法 | 首帧 Pearson | 真实取景（穷举裁剪搜索） |
|---|---|---|---|---|

| v2 | Wan 3.0（`extendPrompt:0`） | 同上 | 0.4116 | 同上（关扩写无效） |

| v5 | Wan 2.7 | 极简 + **静止机位 + 蜂蜜下流 + 尘埃飘移** | 同量级 | **1.90×，(2%,4%)** |

**⇒ 五条被证伪的假设，不要再试**：
① 提示词写法（500 字 → 17 字、类别词 → 特征值 → 四边锚定）
② 关改写开关（`extendPrompt:0`）
③ 进图尺寸（1920 / 1536）
④ 预补偿画布
⑤ **换模型**（Wan 3.0 / Wan 2.7 / C Dance Mini 全都重画）

**⇒ 唯一有效的第三条路就是本文的合成法**——它给出的是老板真正要的东西：
**构图一像素都不变，但油在滴、尘在飘、雾在动。**

## 三、六层结构（每层可单独关掉）

| # | 层 | 做法 | 观感作用 |
|---|---|---|---|
| ① | **液滴下淌** | 球心/半径/柱宽 → 三件套（油柱 / 球体 / 投影）。球体整体平移 `dy`，油柱上端固定、下端跟着拉长，原位用「下方 110px 纹理 + 四边插值」填充，再压一道金色湿痕遮丑 | 全场最抓眼的动作，用户点名的就是这个 |
| ② | **尘粒飘落** | 检测画面里的亮小点（`灰度 − BoxBlur(7) > 22`，NMS 10px，取 260 个），每个点取 9×9 patch + 圆形 alpha，逐帧 `y += v·t`、`x += A·sin(ωt+φ)` | 空气「活」了，最便宜的动感 |
| ③ | **断面热气** | 半分辨率平滑噪声向上滚（2 秒走 46px），`alpha ≤ 0.07`，按「右下半区」加权 | 断面在冒热气的错觉，别超过 0.07 否则发灰 |
| ④ | **暖雾 / 光带呼吸** | 低频噪声按区域加权做亮度调制（顶部光带 ±20%，左侧岩壁 ±13%），叠 0.8Hz 呼吸 | 「石头也在动」的观感来源 |
| ⑤ | **人物呼吸** | 人物框内高斯羽化 mask，脚底权重归零，亚像素上下 1.2px | 人物「微微动」，但不会走位 |
| ⑥ | **推近 + 手持** | zoom 1.00→1.11，叠 ±0.5% 画宽 / ±0.35% 画高的正弦横摆 | 去「静图感」，但**不是唯一动源** |

> **⑥ 是必须但绝不能只有它**：只有推近 = 老板说的「跟放大没区别」。
> 反过来 ①~⑤ 全没有、只有 ⑥，就是 zoompan。

## 四、脚本用法

```bash
python3 ~/.workbuddy/skills/koubo-ad-video/scripts/ambient_motion.py \
  --src "原图.png" --out "出片.mp4" \
  --drop 1039,313,19.5,28 \        # 球心x, 球心y, 球半径, 下落像素（原图坐标）
  --col 1027,1053,226 \            # 油柱 x0, x1, 柱顶y（窄条！见下）
  --person 470,360,730,850 \       # 人物框 x0,y0,x1,y1（可选）
  --zoom 1.11 --dur 2 --tmp /tmp/amb_frames
```

**参数怎么量**（这一步决定成败，别估）：
1. 先把图裁一小块放大 5 倍看液滴，量出 **球心 / 球半径 / 油柱实际宽度**。
   断崖这张：球心 (1039,313)、半径 19.5、油柱 x 1027–1053、柱顶 y=226。
2. `--drop` 的第 4 个数是**下落像素（原图尺度）**：1080 高的图上取 **26–30** 最自然；
   **34 以上油柱会被拉成一根细棍，失真**（实测）。
3. `--person` 给的框要**框住人但别框到断面**，脚底那 20% 会自动归零。

## 五、四个必踩的坑（都已修在脚本里，改脚本时别改回去）

| 坑 | 现象 | 原因 / 解法 |
|---|---|---|
| **油柱取整个 ROI 宽** | 球被「吞掉」成油柱末端一个鼓包 | 油柱必须取**窄条**（本例 26px），两侧各 4px 水平羽化。取 68px 宽会把球周围的肉面一起拉伸 |
| **球体用矩形 patch + 圆 mask** | 球变糊、变形、出现「双球」 | 球体 mask 改成 **金色判定 × 圆形**（`R−B>50 且 R>120`），只平移金色油体，肉面不动 |
| **球体做纵向拉伸** | 末端拉成葫芦 | 不做缩放，只做整体平移。拉长交给油柱 |
| **尘粒原位擦成 mean 色** | 暗部留下灰白小脏点 | 擦除用 **30 分位色**（暗色），alpha 扩到 `PR*0.82` |

## 七、边界（这条不是万能的）

✅ 适合：氛围动 + 一个小物件动（液滴、烟、雾、尘、光、衣角）
❌ 不适合：**人物要走位、要转身、要做动作**——那是真 i2v 的活，合成做不出来
❌ 不适合：需要**新增画面元素**（例子：断面里透出金光）

人物动作只能回 i2v，而 i2v 要求选图过五条硬规则 —— **所以生图阶段就要按 i2v 友好度来构图**，
见 `生图提示词模板.md`。这是本节的真正教训：**别把不能动的图留到出片阶段才发现。**
