# 3D 景深大字 · 三层合成（标准开头 / 卷播都可用）

> **2026-11-06 老板原话**：「今天我们讲形象投资，应该用小绿人在运动或者健身的一张近图，
> 然后**形象投资四个大字有点类似于卷播里面，四个大字出现在小绿人身后，有 3D 景深的效果**」。
>
> 卷播（`MarqueeClickD` + `hero_bg/hero_fg` 拆层）自带这个效果，但**标准开头没有 rem3d**。
> 本文件是「标准开头也要 3D 景深大字」的独立做法：**PIL 逐帧合成 → 出一个 1~1.5s 的 mp4 →
> 当普通 `imgvid` 素材挂进 `shot_map`**。零 Remotion 依赖、零积分、参数可复现。

---

## 一、三层怎么搭

```
hero_bg（场景/空镜，高斯虚化 + 压暗）   ← 底层，给纵深打底
      ↓
字层（金色大字 + 8 向黑描边 + 高斯投影）  ← 中层，居中
      ↓
hero_fg（人物抠像净边 PNG，平移到中轴）  ← 前层，只挡住字的一段
```

**景深不是靠虚化做出来的，是靠「字被人物躯干遮住一段」**。所以选图的第一判据不是「好看」，
是「人物躯干够宽、能横穿字块中段」。本轮「形象投资」四字里，「象」「投」被躯干吃掉一半，
「形」「资」完整 —— 这才是眼睛认的 3D。

## 二、定稿参数（2026-11-06 21金维他烟酰胺 v1 · 四字词）

| 参数 | 值 | 说明 / 依据 |
|---|---|---|
| `size` | **390** | 字块占屏 **75%**（左右各留 12%）。340→66% 气势不够；440→84% 压到边缘 |
| `gap` | 34 | 字间距，四字刚好不挤 |
| `top` | **202** | 字层基线 y，字块纵向居中略偏上 |
| `fg_h` | **1060** | 人物高 = 画面高 98%，**必须是近景**才压得住字 |
| `fg_top` | **−20** | 头顶微微出框，近景感 + 不切断眼睛 |
| `enter` | **0.30** | 入场时长，**必须 > 该镜转场时长**（hblur 0.34s） |
| `sc_in → 1.0` | 1.09 | 起始放大。**不要超 1.15**，字块本身就宽，大了顶出上沿 |
| `sc_out` | 1.03 | 入场后到结尾的缓推 |
| `blur_in` | **6.0** | 入场起始模糊。9 会糊成一片金块，4.5 又看不出「从虚到实」 |
| `op` 入场 | 0.55 → 1.0 | 起始不透明度。0.35 太淡、0.62 太实 |
| `rise` | 46px | 入场同时从下往上浮，纵深感再叠一层 |
| `breath` | 1.012 | 人物呼吸缩放，避免整帧像静图 |
| 颜色 | `#FFD24A` 金 + 8 向黑描边（4px 正交 / 3px 对角）+ 高斯 18 投影 | 压在虚化背景上仍能读清；**禁外发光**（会糊成一团） |

## 三、入场曲线为什么这么写

```
0 → enter           sc 1.09 → 1.0（ease-out cubic）、blur 6 → 0、op 0.55 → 1、y +46 → 0
enter → dur         sc 1.0 → 1.03（ease-in-out sine）、静态之后缓推
```

- **`enter` 必须比转场时长长**。镜 2 前面那 0.34s 会被 `xfade` 和前一镜叠掉，
  `enter=0.18` 时整段「从虚到实」全在混合区里，观众只看到字"已经在那儿了"。
  改 **0.30** 后，入场尾巴正好落在转场结束后，肉眼能看见字浮上来。
- **`sc_in` 和 `blur_in` 是一对**。起始放大越大，同样模糊量下可读性掉得越快；
  1.09 + 6.0 是本轮四组参数里唯一「0s 就看得清是个字、又明显是虚的」的组合。
- **只缓推、不来回**。景深靠遮挡，加位移会让字和人物的相对位置变，遮挡比例就飘了。

## 四、选人物四条判据

1. **必须是净边抠像 PNG**（`_抠图库/角色/*_净边.png`），不是带背景的图。
2. **躯干要宽**：正面推举、直臂、抱臂好；侧身、单臂、弯腰差（挡不住中段）。
   本轮从「哑铃弯举 980 高」换到「站姿推举 1060 高」才立住 —— 杠铃横穿 + 躯干宽。
3. **人物高 ≥ 画面 95%**：中景/全景压不住 390 号字。头顶可以出框，眼睛不能切。
4. **别选张开双臂的动作**：会把字块左右两端也吃掉，变成"字在身后看不见"。

底层 `hero_bg` 优先用同场景**空镜**（`_通用池/场景空镜/`），比从人物图补背景干净得多；
没有空镜就用同色系虚化背景图，压暗到 0.72、饱和度 0.92，让金字跳出来。

## 五、命令

```bash
SK=~/.workbuddy/skills/koubo-ad-video/scripts/hero_label_3d.py

# ① 先出候选矩阵挑 size / top（**不许跳过**，直接渲视频等于盲打）
python3 $SK matrix \
  --bg "…/_通用池/场景空镜/场景_空镜健身房_大远景.png" \

# 每格会打印「字块总宽 x%（屏宽）」，挑落在 70~78% 那一列，再看遮挡位置

# ② 定稿渲（时长 = 该镜实际镜长，或稍短让 pipeline 自己 clone 补尾）
python3 $SK render \
  --bg "…空镜健身房…png" --fg "…站姿推举…净边.png" \
  --text 形象投资 --size 390 --gap 34 --top 202 \
  --fg-h 1060 --fg-top -20 --dur 1.24 \
  --out assets/宣言_形象投资_景深.mp4
```

产出直接当 `imgvid` 挂进 `shot_map`：

```json
{"src":"…/assets/宣言_形象投资_景深.mp4","kind":"imgvid","no_zoom":true}
```

## 六、验收（三条，缺一不可）

1. **0s / 中段 / 末段各抽一帧**：0s 必须「看得出是字但明显虚」，中段字清晰、末段仍清晰。
2. **字块左右各留 ≥ 10% 屏宽**：抽帧量一下最外侧字的像素边界。
3. **字顶不撞画面上沿**：`sc_in` 那 0.09 的放大作用在整幅字层上，起始时字块最高点最容易顶出去。
   判据：0s 帧里最上面那个字的上沿到画面顶边 ≥ 40px。

## 七、踩过的坑

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 0s 那一帧糊成一片金色，读不出字 | `blur_in=9.0` 太大 + `op` 起点 0.35 太低 | 9→4.5→**6.0**；op 0.35→**0.55** |
| 2 | 字块压到画面左右边缘，像贴边裁过 | `size=400` 时四字块占屏 86% | 400→360（留白够了但气势弱）→**390**（75%，气势与留白兼顾） |
| 3 | 起始帧字顶撞掉画面上沿，第一个字只剩半截 | `sc_in=1.22` 起始放大过大（字块本身宽） | sc_in→**1.09**，并加 `rise` 上浮 46→0 补纵向动感 |
| 4 | 入场完全看不见，字像"已经在那儿" | `enter=0.18` 全程落在转场混合区（0.34s）里 | enter→**0.30**，尾巴落到转场之后 |
| 5 | 人物太小，字把人物挡住，景深反了 | 选了哑铃弯举 980 高（占屏 91%） | 换**近景 1060 高 + 躯干宽**的站姿推举；`fg_h` 不低于画面 95% |
| 6 | 抽帧验「重点字出没出」误判成没出 | 忘了成片前面还贴了 **0.50s 封面帧**，fx spec 用的是底片时间轴 | 抽帧时间 = `startSec + 0.50 + 0.4` |

## 九、2026-11-08 增补：延迟入场（t0）+ 水平滑入（slide）

英之素黑麦片两字词「燕麦」返工两轮后新增四个参数，解决「字出太早、动效不够」。

| 新增参数 | 含义 | 本片值 |
|---|---|---|
| `t0` | **延迟起点**：t<t0 只画底图+人物、不画字；t0 对齐“讲”字结束的画面时刻 | 1.89 |
| `op_in` | 入场起始不透明度（原 `op` 起点 0.55 拆出），做淡入 | 0.6 |
| `slide` | 水平滑入方向：`left`/`right`/`none` | right |
| `slide_px` | 入场起始水平偏移，边滑边回到居中 | 360 |

**本片定稿参数（两字词，dur 2.52）**：size 560、gap 34、top 260、fg_h 1060、fg_top −20、
enter 0.45、**sc_in 0.5**、sc_out 1.03、blur_in 4、op_in 0.6、slide right、slide_px 360、rise 0。

**★ 缩放方向的坑（最容易反）**：
- `sc_in` 是入场**起始**缩放、再缓动到 1.0。
- 要“**从小到大**”必须 **sc_in < 1**（本片 0.5）；若给 1.45 会变成“从大到小”，与诉求相反。
- 自检：抽 t0 后第一帧看字的大小，别等整段看完才发现方向反了。

**滑入与旧“不位移”说法的关系**：第三节说的“加位移会让遮挡比例飘”，指的是**到位后**还在动；
`slide` 只作用在**入场阶段**（t0→enter），字到位后居中、静止，遮挡关系不变，两者不冲突。
配合 `blur_in`（起始虚、滑入中变清晰），“推进来”的观感更明显。
