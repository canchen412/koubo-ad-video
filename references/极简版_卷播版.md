## 一、形态定位：四选一里的第 ④ 项（不做二次追问）

**2026-11-08 老板最终定法**：开工只问一次，四项平级 ——**① 标准版 / ② 标准版（卷播开头）/ ③ 极简版 / ④ 极简版（卷播开头）**。
本篇＝**④**，与 ③ 并列摆在同一次提问里；**不再"先选极简、再选卷播"问两轮**（老板原话：「就不用第二层了，第一层可以把这个事情交代完，直接选一下就行」）。

| 选项 | 片头 | 适用 |
|---|---|---|
| **③ 极简版** | 首句直接上贴纸（漫画墙 + 人物弹入） | 默认、最快；文案首句没有"盘点感" |
| **④ 极简版（卷播开头）** ← 本篇 | **首句就是卷播**：6 张卡滚动 → 减速定格 → 主图放大 + 白边相框 + 余震 →（可选）大字动效 | 要开场有设计感、产品或卖点能做成卡；首句是"今天我们讲 X"这种起手句 |

**④ 是"镜 1 换了个拍法"，不是"加了个片头"** —— 它不是贴片，吃的是第 1 句的时间轴。
（所以也可以在需要时吃第 2 句：`--banner-frames` 拉长即可。）

## 二、六步工序（不许跳步、不许换顺序）

```
① plan.json（照常排 11 镜；s01 仍然写贴纸/卡片，卷播段只是把它"前置放大"）
        ↓
② banner_onbg.py  →  卷播段 mp4（67 帧 / 2.225s）
        ↓
③ minimal_render.py --start 2.225  →  正文段 mp4（总帧数 − 67）
        ↓
④ mux_banner_cut.py  →  整条音频（原 mix 前段叠卷播音效 + 后段原样）
        ↓
⑤ concat copy + 混音 + 响度链 + -t  →  正片
        ↓
⑥ add_cover_frame.py  →  封面接进第 0 帧（+15 帧 / +0.5s）
```

**⑥ 是 2026-11-08 新增、且是硬要求**：老板「封面放在这个视频的第一帧，这第一帧就默认是抖音的封面」。
极简版卷播版没有 pipeline 6.5 步，必须手接：

```bash
PY=/Users/yourname/.workbuddy/binaries/python/envs/default/bin/python
$PY ~/.workbuddy/skills/koubo-ad-video/scripts/add_cover_frame.py \
    --video 正片.mp4 --cover 封面.jpg --out 带封面.mp4 --dur 0.5
$PY ~/.workbuddy/skills/koubo-ad-video/scripts/check_cover_frame.py \
    --video 带封面.mp4 --cover 封面.jpg --body-frames <正片帧数>
```

- 封面本身走 `cover-design` 的 **`photo` 零字实景直裁**（`crop_photo.py`）——不带标题、不带色块；
- 接完总帧数 = 正片 + 15，时长 +0.5s；音频 `adelay=500` 后移，第一句仍与画面严丝合缝；
- 交接时务必把「正片帧数」记下来（卷播 67 + 正文 N），闸门要靠它算总帧数。

### ① plan 不变，但两件事必须一起定

- **背景**：`bg` 显式写预设（如 `W2`）。卷播段和正文段**必须是同一张墙、同一个 seed**，
  否则接缝会跳（`bg_lib.frame(t)` 是 t 的确定函数，同参数跨实例差只有 3.3，肉眼零跳变）。
- **卡池**：卷播用一套独立卡（见 §三），**主图必须是卡列最后一张**，`banner_onbg` 会自动校验。

### ② 卷播段

```bash
PY=/Users/yourname/.workbuddy/binaries/python/envs/default/bin/python
SK=~/.workbuddy/skills/koubo-ad-video

$PY $SK/scripts/banner_onbg.py \
  --cards-file banner_cards/cards.txt --out /tmp/banner.mp4 \
  --dur 2.225 --focus-at 1.05 --an-dur 0.34 --card-sec 0.26 \
  --bg W2 --no-sub \
  --kw-alpha banner_cards/hero_alpha.png --kw-t0 1.34 \
  --v-hold 3 --shake-amp 6
```

| 参数 | 2026-11-08 定值 | 说明 |
|---|---|---|
| `--dur` | 2.225 | = 第一句配音时长 + 0.04；等于 67 帧 |
| `--focus-at` | 1.05 | 定格时刻。**宁早不晚**：定格后还要留给放大 + 大字 |
| `--an-dur` | 0.34 | 定格后"跳出来"的位移动画，超过 0.5 会拖 |
| `--card-sec` | 0.26 | 每张卡实占 0.21s。0.21 太闪、0.40 看得清但只够 3 张 |
| `--kw-t0` | 1.34 | 大字起手（定格 + 0.29s），对齐配音说到"燕麦" |
| `--v-hold` | 3 | 段 3 卡列残余转速，0 = 死板 |
| `--shake-amp` | 6 | 落位余震。8 以上晕 |
| `--bg-seed` | 7 | **必须与 `minimal_render --seed` 一致**，颗粒才接得上 |
| `--no-sub` | 必带 | 卷播内不出字幕，交给成片渲染器统一出，否则双层 |

### ③ 正文段（跳帧渲）

```bash
$PY $SK/scripts/minimal_render.py --plan plan.json --vo vo_index.json \
  --out /tmp/body.mp4 --bg W2 --seed 7 --crf 19 --start 2.225
```

`--start` 让渲染器从第 67 帧开始出，但 `tt` 仍按**绝对时间**算 ⇒ 背景帧号、字幕时间、贴纸时序全部天然对齐，
不会出现"从头渲再裁掉前 67 帧"那种半帧错位。

### ④ 音轨（不重建时间轴）

```bash
$PY $SK/scripts/mux_banner_cut.py --mix out/mix.wav --out /tmp/full_audio.wav \
  --total-frames 877 --banner-frames 67 --focus 1.05
```

只做两件事：把滚动声拉伸到定格点、把"咚"压在定格点，**整条音频还是原来那条 mix**。
这样卷播和口播共用同一个时钟，第一句一字不差地对在起手上。
音效素材在 `assets/sfx_banner/`（滚动 + 定格咚）。

### ⑤ 拼片 + 响度

```bash
printf "file '%s'\nfile '%s'\n" /tmp/banner.mp4 /tmp/body.mp4 > /tmp/cat.txt
ffmpeg -y -f concat -safe 0 -i /tmp/cat.txt -c copy /tmp/joined.mp4
ffmpeg -y -i /tmp/joined.mp4 -i /tmp/full_audio.wav \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k \
  -af "loudnorm=I=-8.5:TP=-1.0:LRA=11,alimiter=limit=0.95:level=0,aresample=44100" \
  -t 29.233333 -movflags +faststart 成片.mp4
```

- **`-t` 必给**（= 总帧数 ÷ 30）：loudnorm 有延迟，音频比视频长 2 帧，不加容器时长会被拉到 29.30。
- 响度链用技能标准那条 **I=-8.5**，实测输出 −13.9 LUFS / TP −0.9，与 261031 的 v7 同一水平。
  ★ 别用 `I=-13` 两段式手传 `measured_*`，那会把电平压到 −24。

## 三、卡池怎么出

卷播卡不是普通分镜图，是**竖幅 890×500 的横卡**（16:9 卡槽，与主图比例一致，contain 后几乎无黑边）：

- 卡底：**深炭竖渐变 (26→58) + 极淡网点**，底部 4px 亮线。这是本系列的视觉语言，别改成浅底。
- 卡内容：角色贴纸（先裁 bbox 再统一 `h=1006`，脚底基线 1050）
- 同批多条：**卡池零复用**、开场顺序不同、主图不同
- 另出两个附件：
  - `hero.jpg` —— 主图（16:9 完整图，段 3 靠它放大，不能用竖卡strip）
  - `hero_alpha.png` —— 1920×1080 人物遮罩（大字要压在人物身后，靠它逐帧挖洞）

## 四、大字动效（可选，`--kw-alpha`）

`scripts/kw_card.py` 的 `KwLayer`：吃一张人物遮罩 png，吐逐帧 (前景层, 阴影层)。

时间线（`T_DOT=0.30 HOLD=0.10 BURST=0.10 GAP=0.05 GROW=0.40 FLY=0.20`）：

```
0.30  小圆点浮在人物身上
0.40  圆点横向撕开（16→74px）→ 双字同时出生（不是分两次！老板纠过一次）
0.50  过冲 4% 站定（easeOutBack c1=1.22，1.9 会撑出卡框）
0.70  0.40s 从卡心滑到两侧就位（easeOut exp(-10p)）
0.90  定格
```

关键三条：
1. **点画在人物之上、字沉在人物之下** —— 二者不可兼得，字在人物身后才有 3D 景深，那点就只能浮在人物身上。
2. **描边只用 `sw_k=0.012`**（6px）。0.062 会把"燕"糊成黑块。
3. **深底别加投影**，只留 7px 厚度；投影在暗底上是一团雾。

### 字数是 2 字还是 4 字（★2026-11-09 老板拍板）

老板原话：「今天我们讲形象优先，形象优先是**四个字**，但这里跳出来是两个字，你改成四个字。」

`--kw-chars` 直接传，2 字和 4 字都收，不用改脚本：

| 字数 | 版式 | 字号 | 场景 |
|---|---|---|---|
| **2 字**（默认） | 左右各一字分立两侧，中间整条留给人物 | `ch·0.6795`（放大后 ~424） | 「燕麦」「肌酸」这类双字卖点 |
| **4 字** | 横排铺满卡宽、字心均分（0.125/0.375/0.625/0.875），中间两字压在人物身后 | `min(ch·0.6795, cw·0.90/n)`（放大后 ~250） | **口播说的是四字短语**（形象优先 / 免疫屏障 / 增肌减脂） |

- **口播念几个字，画面就必须出几个字** —— 只出前两字会被打回（这次就是 `--kw-chars 形象` 少写了两字）。
- 4 字必然比 2 字小：卡宽就那么宽，四字要全入画只能缩。**别为了保字号让字顶出卡框**（`cw·0.90/n` 里的 0.90 就是两侧各留 5% 的保险量，调到 0.94 会贴边显裁）。
- 中间两字被人物手臂挡一部分是**正常的景深**，不是 bug；四字仍须逐个可辨。
- `KwLayer` 只认 2 或 4 字，传 3 个字直接 `ValueError` —— 三个字的口播短语就补成四字或压成两字，别硬塞。

## 五、踩过的坑（每条都返过工）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 卷播做成片头贴片，播完才开始说第一句 | 把卷播当"片头素材" | 卷播**吃镜 1**，和第一句共用时间轴 |
| 2 | 卷播段背景是黑的、正文是漫画墙，接缝一大跳 | 卷播单独用 `np.zeros` 底 | `--bg` 传同一预设 + 同 seed，`bg.frame(t)` 跨实例零差 |
| 3 | 卡片周围留一圈黑块 | `img[...] = pxc*pa` 直接赋值，只对黑底成立 | 改真混合 `img = pxc*pa + img*(1-pa)` |
| 4 | 落定后画面上一块暗矩形 | 段 3 有"主卡周边压暗 0.62"，黑底看不见、漫画墙露馅 | 删掉该逻辑 |
| 5 | 落定后右边一直站着个多余小人 | 段 3 卡列继续转，把相邻卡的深炭块和裸贴纸露出墙外 | `pa *= (1 - min(1,(fi-NFF)/FPS/0.30))`，0.30s 内淡出 |
| 6 | 浅灰影棚底（LB）上，两侧卡像黑砖贴在白墙上 | 深炭卡只在**比它更暗**的墙上有边界感 | 深炭卡就配深底漫画墙（W1–W7）；浅底留给其他版式 |
| 7 | 容器时长多 0.07s、末尾两帧黑 | loudnorm 有延迟 | `-t <总帧数/30>` |
| 8 | 抽帧看整段是空白，以为成片坏了 | 对 concat 出的 mp4 用 `-ss 5.0 -i`（前置 seek） | 改 `-i file -ss 5.0`（后置精确 seek） |
| 9 | 滚动前半段白框里是空的 | 节距 980 > 卡宽 890，框落在 90px 空隙上 | 正常现象，V1 同样如此，不是 bug |
| 10 | 大字分两次出生（先燕后麦） | 两字各自起手 | 同一个圆点、同帧双字 |
| 11 | "麦"字起手左右不对称 | 字面窄、视觉重心偏 | 字号 ×1.06 + 0.04s 起手淡入 |
| 12 | 同批两条片背景撞 | 忘了轮换 | `batch_plan_check.py` 过闸，同批背景互不相同 |
| 13 | 大字永远画成「燕麦」，换品类也不变 | `kw_card.KwLayer` 把字写死 `("燕","麦")` | **2026-11-08 已修**：`KwLayer(im, chars=(...))` + `banner_onbg.py --kw-chars 肌酸`（默认仍「燕麦」，旧片不受影响） |
| 14 | 大字越放大越往卡框外飘，「肌」左半被白框切掉 | `cx_l/cx_r/cx0` 只在 `_prepare()` 按**首帧**卡宽算死，段3 卡在放大、字被 `k` 放大，字心却钉在旧坐标 | **2026-11-08 已修**：`frame()`/`dot()` 里每帧按当前 `cw` 重算三处中心 |
| 15 | **整条片一个重点字都没有**（「今天我们讲，燕麦」的「燕麦」两个字始终没出现），而 plan 三道闸门全绿 | 渲 banner 时只传了 `--no-sub`，**漏了 `--kw-alpha` / `--kw-t0`** ⇒ 卷播段只剩卡列滚动 + 主图放大。又因为卷播吃镜1 **整镜替掉 s01**，那个重点字没有任何别的镜位承载，等于全片丢失。plan 闸门只看字段（`kw` 写着「燕麦」就放行），不看渲染结果（2026-11-09 燕麦 v1 实撞，老板一句「燕麦那两个字怎么没有出来呢」） | 渲卷播**必带三件**：`--kw-alpha banner_cards/hero_alpha.png --kw-t0 <秒> --kw-chars <字>`。出片后必跑闸门 `scripts/check_banner_kw.py --video 成片.mp4`（默认扫 0–3s），exit 0 才算过；正例峰值 ≈0.047，无字镜 ≤0.0024，区分度 20 倍。**`hero_alpha.png` 做了不用＝没做。** |
| 16 | 大字确实出了，但**刚站稳就被切走**（约 0.19s），一闪而过 | `--kw-t0` 直接照抄了 261108 的定值 1.34。kw 时间线要 0.3 圆点 + 0.1 撕裂 + 0.1 站定 + 0.4 滑到位 = **0.9s 才完全就位**；本片第一句 2.131s、配音念「燕麦」在 1.744s，1.34 起手 ⇒ 2.24s 才站定，2.67s 就切镜 | **kw-t0 按「配音念到该词的时刻 − 0.75s」反推**（本片 1.744 − 0.75 ≈ 1.00），让字在念出来的那一口气上刚好站定，留 0.4–0.5s 稳定停留。判据：抽 t=词起点 与 t=词终点 两帧，两帧都必须是**已就位**的字 |
| 15 | 传了 `--kw-alpha` 却一个字都不出 | 遮罩格式错了：`KwLayer` 走 `convert("L")`，**吃的是亮度**。拿了「白底 + alpha 人像」的 PNG 进去，亮度全是 255 ⇒ 全片当人物挖空 | `hero_alpha.png` 必须是**灰度亮度图**（人=255 / 背景=0）：`Image.open(hero_fg.png).getchannel("A").save(hero_alpha.png)`。别存成 RGB+alpha |
| 16 | 人物太宽，`--kw-scale 1.0` 时字顶出卡框 | `R_SIZE=0.6795` 是按燕麦的窄人物调的 | 加 `--kw-scale 0.75~0.85`（肌酸 v1 用 0.78 正好贴住两侧、与人物各让一半） |
| 17 | **成片最后一句语音整个没了**（39.5s 之后静音到底），画面正常 | `minimal_audio.py mix --video` 传了**正文段**（`--start 2.5` 渲出来的 38.87s，已扣掉卷播 2.5s）。timeline 是按**完整成片时间轴**（41.37s）铺的，mix 被视频长度裁到 38.87s ⇒ timeline 38.87s 之后全丢（正好是末句后半） | 先 `ffmpeg -f concat` 把「卷播 + 正文」拼出完整片（41.37s），再拿它当 `--video` 混音。**顺序：先 concat 再 mix，不是先 mix 再 concat** |
| 18 | 口播念「形象优先」四个字，画面只跳出「形」「象」两个 | ① `KwLayer` 原本硬校验「正好 2 字」；② 更常见的真实原因：**`--kw-chars` 只传了前两个字** | 传满四个字 `--kw-chars 形象优先`（2026-11-09 起 4 字走横排铺满版式） |
| 19 | **第一帧变成卡墙，竖版封面没了**（用户一眼就看出「这个封面不对」） | 只改卷播段的返工：`banner_onbg.py` 渲出来的段是**纯卡墙、从第 0 帧就开始滚**，而原片开头是「封面 15 帧 + 卷播 130 帧 + 正文」。拿新 banner 直接接正文 ⇒ 总帧数碰巧对得上（145+986=1131），封面被卡墙顶掉，且不易察觉 | 返工必须拼**三段**：`旧片 trim=end_frame=15` + `banner(130帧/4.333s)` + `旧片 trim=start_frame=145`。**卷播时长要按「原片切入帧 − 15」重算**，不能直接沿用原来 4.833 的目标值 |

## 六、验收清单

- [ ] `ffprobe`：总帧数 = 卷播 67 + 正文（总 − 67），30fps，1920×1080
- [ ] 0–2.23s：第一句话起手时卡已开始滚；定格在 `--focus-at`；大字在 `--kw-t0`
- [ ] 2.23s 接缝：背景格子连续、无黑帧、无跳色
- [ ] 电平：`-13.9 LUFS` 上下、TP ≤ −0.7、与同批另一条差 ≤ 0.3dB
- [ ] **末句念完了**：抽最后 3 秒跑 ASR，或看 0.5s 粒度的 RMS 包络——末尾不得从某点直接掉到 −180dB；
      掉到静音 = 第 17 条那个坑（mix 的 `--video` 传短了）
- [ ] 闸门：`minimal_plan_check.py` exit 0；`batch_plan_check.py` exit 0（多片）
