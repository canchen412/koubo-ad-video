# 静图运镜：匀速 vs 冲镜（★2026-11-11 老板定稿入库）

静图（分镜图库里的 jpg）进片有**两种**运镜手法，按台词语气挑，不要一律匀速。

---

## 一、选型：什么时候用哪种

| 手法 | 脚本 | 观感 | 用在哪 |
|---|---|---|---|
| **匀速**（Ken Burns） | `scripts/still_to_clip.py` | 缓缓推近/平移，安静 | 交代场景、情绪铺陈、人物思考、过渡镜 |
| **冲镜**（静—猛—定） | `scripts/still_punch.py` | 先定住半秒，再一顿猛推怼到脸上，然后死定 | 台词在「砸实」一个具体东西：包子油条、糖油堆、数字、包装、价签 |

**判据一句话**：这一镜的台词如果是「就是这玩意儿」，用冲镜；如果是「我来说个事」，用匀速。

老板 2026-11-11 原话：「以后如果有类似的近图的话，你也可以做做这种推进的处理。」
⇒ **静图默认要过一遍冲镜判据**，不是默认匀速。

---

## 二、★ 连推上限：最多 2 镜，第 3 镜必须换

**铁律（2026-11-11 老板定）**：连续冲镜**最多两镜**，第三镜一定腻。

> 原话：「连续两次是可以的，但是不能连续三次都做这样的推进，不然就会腻了。」

执行细则：

1. 同一个连续段落里，冲镜计数从 1 开始，到 2 就必须归零
2. 第 3 镜强制换成：匀速推/平移、视频素材、其他镜别（全景、俯拍、卡片）
3. 计数只看**时间轴相邻**，中间隔了任意一个非同手法镜头即可重新计 1
4. 三条片同批时，各片独立计数，不跨片累加

已验证的好处：连推两次形成「哐—哐」的压迫感，第三镜松开，观众注意力才回来。

反面案例（2026-11-11 蛋白吐司 v1）：
```
镜3 早餐摊→包子油条  冲镜 ✔
镜4 糖油堆           冲镜 ✔（第二记，力度持平 2.1 倍，观感统一）
镜5 厨房托腮         ← 必须松开，保持原匀速 pan_l，不许再推
```

## 三、冲镜参数（still_punch.py）

```bash
python3 scripts/still_punch.py <图片.jpg> \
  --dur 2.2 \                # ★必须等于该镜 trim 值，宁长勿短
  --focus 0.31,0.55 \        # ★归一化焦点，推近后框住谁就写谁
  --z1 2.1 \                 # 终点倍率：1.9~2.2 怼脸 / >2.3 会软
  --hold 0.5 \               # 静止段，冲击力的来源
  --push 0.52 \              # 爆发段：0.34 极猛 / 0.52 稳
  --sfx                      # 把 riser+impact 压进片段
```

节奏三段：
```
0.00 ─ hold        全景定住（只有 3% 的极缓推，让静止有呼吸）
hold ─ hold+push   猛推到 z1×1.03 再回落到 z1（过冲 3%）
之后 ─ 结束        死定，一动不动
```

**为什么要有 hold 段**：一开头就推，观众眼睛还没落到画面上就被推走了；先定住半秒再猛推，才显得「突」。

## 四、必须踩对的四个坑

### 坑 1 · `--dur` 要从 `filter_debug.txt` 读，不许从 `subs.ass` 读

`subs.ass` 是按**语音句**切的，一镜可能对多句，也可能是句内切镜，时间轴与镜界**对不上**。

唯一可靠来源是渲染产出的滤镜链：
```bash
grep -oE "trim=duration=[0-9.]+" <工程>/v1/filter_debug.txt
```
第 n 个值就是第 n 镜的时长。

**短了的后果**：`build_ad_video.py` 会用 `tpad` 冻末帧硬撑，节奏被拉长、总长偏移，冲镜的「定住」变成「拖住」。
2026-11-11 镜3 第一次做 2.767s，实际 trim 3.072s，被 tpad 补了 0.305s。

### 坑 2 · 焦点偏右会留「人体残影」

小绿人常站在食物堆右侧。焦点设正中（如 0.36）时，2.1 倍取景窗右边界刚好卡在他手臂内侧，**右上角会留约 5% 的绿色人体边缘**，推到满反而更显眼。

做法：焦点向食物堆核心左移（如 0.36 → 0.31），让绿色完全出画。代价是左侧边角被切，但这一镜要的是「满屏」，切掉反而更满。

**抽帧验收**：定格帧抽出来单独 crop 右上角 640×360 看一遍，别只看缩略拼图。

### 坑 3 · `--sfx` 必须配 `ambient_gain: 1.0`

片段里压进去的 riser/impact 走的是「素材原声」通道，`imgvid` 镜默认把原声压到 **0.14** 当环境垫音，音效等于没了。

分镜表要写：
```json
{ "src": "...冲镜定格2.2s.mp4", "kind": "imgvid", "no_zoom": true,
  "ambient": true, "ambient_gain": 1.0 }
```

（2026-11-11 之前 `pipeline_run.py` 的 shot_map 字段白名单漏了这两个键，写了也被吞；现已补上。）

验收：`ffmpeg -lavfi showspectrumpic` 出频谱图，应能看到一条横跨频段的垂直亮线（impact）+ 低频到高频的斜线（riser）。

### 坑 4 · `no_zoom: true` 必开

片段本身已经在动，再让 build 层推一次会重复运镜、也糊。冲镜/匀速片段一律 `"no_zoom": true`。

## 五、入库命名

放 `分镜图库/<IP>/<品牌>/视频/`，文件名带原图名 + 手法 + 时长：

```
避坑_早餐摊油条前摆手_中景_冲镜定格3.1s.mp4
避坑_糖油混合物堆前摆手_全身_冲镜定格2.2s.mp4
痛点_厨房台面托腮思考_中景_匀速推_2.7s.mp4
```

同一张图可以做多个时长版本（2.8s / 3.1s），一起留着，写分镜表时按 trim 值直接挑，不用重做。

## 六、冲镜与「科普段零产品」的关系

冲镜是**画面强度**手段，不改语义。科普段（点名产品之前）照样可以冲，但推的必须是痛点物（包子、油条、糖油堆、空餐盘），**不许推产品包装**——产品要等转折点之后才出现。

产品段的冲镜只用在包装/价签/成分表这类「要看清」的地方，且同样受「连推最多两镜」约束。
